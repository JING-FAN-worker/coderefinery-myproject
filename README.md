# CodeRefinery My Project

Practice repository for CodeRefinery Day 2 exercises.

## Purpose

This project contains a simple Python greeting program.
It is used to practise creating a repository, committing changes,
and sharing code on GitHub.

## Requirements

Python 3.6 or later. No additional packages are required.

## How to run

Download or clone this repository, open a terminal in its folder,
and run:

```bash
python3 hello.py
```

Expected output:

```text
Hello, Jing! Welcome to CodeRefinery.
```
